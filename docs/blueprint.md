# **App Name**: NumberNet

## Core Features:

- Secret Number Entry: Game setup: Player 1 enters a 4-digit secret number with digits that can be repeated for Player 2 to guess, and vice versa.
- Guess Input: Provide a user interface for players to input their guesses.
- Guess Validation: Guess validation: Check if the guessed number is a valid 4-digit number with digits that can be repeated.
- Guess Comparison: Comparison engine: Compare the guess with the secret number and provide feedback in terms of number of correct digits on correct positions and number of correct digits in wrong positions
- Results Display: Display results: Display the history of guesses with the respective comparison result.
- Real Time Updates: Real-time updates: Allow guesses and result update as the game is being played in real time

## Style Guidelines:

- Primary color: A calm blue (#4681C4) to promote focus and intellectual activity, suitable for a game of logic.
- Background color: Light gray (#E0E5EA), providing a muted backdrop that doesn't distract from the numbers.
- Accent color: Yellow-orange (#C46E46) as it sits near to red in the color palette for highlighting feedback and actions, signaling warm but wrong numbers and guesses.
- Body and headline font: 'Inter', a grotesque sans-serif with a modern look for both headlines and body text, given the short length of the text anticipated.
- Use simple, clear icons to represent game actions like submitting a guess or generating a new game.
- Maintain a clean, tabular layout to present the number guesses and feedback in an organized manner.
- Incorporate subtle animations to provide feedback after each guess submission.
